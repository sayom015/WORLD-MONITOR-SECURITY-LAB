# REFERENCE DATASETS

The following external resources serve as the authoritative baseline, architectural inspiration, and feature reference datasets for the simulated local security lab.

## Web Application Dataset
- **URL**: [https://www.worldmonitor.app](https://www.worldmonitor.app)
- **Role in Lab**: Serves as the functional reference for building the simulated UI, dashboard components, and API structure.

## Source Code Dataset
- **Repository**: [https://github.com/koala73/worldmonitor](https://github.com/koala73/worldmonitor)
- **Role in Lab**: Serves as the architectural reference dataset for mapping potential threat vectors, data flows, and middleware concepts to the local simulation.

---

### ⚠️ Security Notice
These datasets are provided strictly as reference material for this academic project. **The automated testing harness and security scripts inside this lab are hardcoded to test `localhost` only.** No active security testing, scanning, or exploitation is performed against these production URLs.
